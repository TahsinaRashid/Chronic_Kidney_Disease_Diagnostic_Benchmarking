# Chronic Kidney Disease Classification using Machine Learning

## Project Overview
This project focuses on diagnosing Chronic Kidney Disease (CKD) using multi-model classical machine learning architectures. The dataset undergoes comprehensive preprocessing, including numeric median imputation and label encoding, to ensure clinical data integrity.

## Key Technical Features
* **Exploratory Analytics:** Structured mapping of patient diagnostic parameters.
* **Missing Value Imputation:** Resolving missing lab values via automated `SimpleImputer` routines.
* **Architectural Benchmarking:** Comparative synthesis between Logistic Regression, K-Nearest Neighbors, and Random Forest models.
* **Visual Synthesis:** Horizontal track metric mapping for optical performance assessment.
